# 151종 몬스터 디자인 원장

기준 문서: `Docs/몬스터_디자인_품질기준.md`

이 문서는 이미지 생성 전에 보는 정본 디자인 원장이다. 도감 번호, 이름, 진화 구조는 `Docs/151종_몬스터_스프라이트_생성_기획서.md`의 도감 번호 기준 원장을 따른다.

## 공통 생성 방향

- 고전 몬스터 수집 RPG의 문법은 참고하되 특정 기존 캐릭터를 복제하지 않는다.
- 각 종은 `몽글이`, `플로린`, `도토넷`, `이슬방울`, `종이접기` 샘플처럼 한눈에 읽히는 고유 소재가 있어야 한다.
- 같은 필드라도 몸통, 대표 파츠, 실루엣이 겹치면 폐기한다.
- 모든 항목은 48x48에서 읽히는 대표 파츠를 우선한다.

## 검수 규칙

1. `unique_key`가 완전히 같은 행은 없어야 한다.
2. 같은 진화군 안에서는 `evolution_delta`가 반드시 이어져야 한다.
3. 이미지 생성 시 `image_prompt_core`를 그대로 프롬프트 중심 문장으로 사용한다.
4. 48x48에서 `signature_shape`가 안 보이면 해당 행은 디자인 실패로 되돌린다.
5. 이 원장에서 승인된 행만 이미지 생성 대상으로 삼는다.
