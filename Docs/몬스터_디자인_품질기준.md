# 몬스터 디자인 품질기준

이 문서는 151종 몬스터 스프라이트 재작업의 기준선이다.

## 승인된 방향

기존 `mongle`과 새 샘플 4종을 기준으로 한다.

| id | 역할 | 승인 포인트 |
|---|---|---|
| mongle | 기준 몬스터 | 둥근 새싹 젤리 실루엣, 단순한 얼굴, 적은 파츠로 기억됨 |
| florin | 풀 타입 예시 | 꽃잎 머리 + 작은 식물 몸통이 한눈에 읽힘 |
| acornet | 숲/벌레 예시 | 도토리 투구 + 작은 벌레 다리라는 고유 소재가 분명함 |
| dewdrop | 물 타입 예시 | 물방울 몸통 + 아가미 지느러미 실루엣이 분명함 |
| origami | 사무실/종이 예시 | 접힌 종이 생물이라는 소재가 실루엣으로 드러남 |

샘플 파일:

- `Assets/Sprites/ConceptSamples/florin_concept_v1.png`
- `Assets/Sprites/ConceptSamples/acornet_concept_v1.png`
- `Assets/Sprites/ConceptSamples/dewdrop_concept_v1.png`
- `Assets/Sprites/ConceptSamples/origami_concept_v1.png`

## 디자인 원칙

1. 색만 바꾼 몬스터는 폐기한다.
2. 같은 둥근 몸통에 장식만 얹은 몬스터는 폐기한다.
3. 각 종은 한 문장으로 설명되는 고유 소재를 가져야 한다.
4. 48x48에서 검은 실루엣만 봐도 종이 구분되어야 한다.
5. 얼굴은 작고 단순하게 유지하되, 대표 파츠가 먼저 읽혀야 한다.
6. 진화체는 단순 확대가 아니라 대표 파츠가 성장해야 한다.
7. 특정 기존 캐릭터를 직접 복제하지 않는다. 다만 고전 몬스터 수집 RPG의 문법은 참고한다.

## 개별 디자인 원장 필수 필드

이미지 생성 전, 각 도감 번호마다 아래 항목을 먼저 채운다.

| 필드 | 설명 |
|---|---|
| dex_no | 도감 번호 |
| id | 영문 식별자 |
| ko_name | 한국어 이름 |
| en_name | 영어 이름 |
| evo_group_id | 진화군 |
| evo_stage | 현재 진화 단계 |
| evo_total | 전체 진화 단계 |
| core_concept | 한 문장 고유 컨셉 |
| silhouette | 48x48에서 보이는 외곽 형태 |
| body_structure | 몸통, 머리, 팔, 다리, 꼬리, 날개 구성 |
| signature_shape | 반드시 보여야 하는 대표 파츠 |
| face_rule | 눈, 입, 표정 규칙 |
| palette | 본체색, 외곽선, 그림자, 하이라이트, 포인트색 |
| texture_material | 젤리, 잎, 종이, 물방울, 돌 등 소재감 |
| pose | 정면, 3/4, 웅크림, 떠 있음 등 |
| evolution_delta | 이전/다음 단계와 달라지는 부분 |
| unique_key | 중복 방지 키 |
| forbidden_overlap | 겹치면 안 되는 다른 종/소재 |
| image_prompt_core | 이미지 생성용 핵심 문장 |

## 이미지 생성 프롬프트 기준

모든 프롬프트는 아래 구조를 따른다.

```text
Use case: stylized-concept
Asset type: Unity 48x48 pixel monster sprite source
Primary request: Create an original monster-catching RPG pixel sprite named <id>, <core_concept>. Unique concept: <signature_shape and body_structure>. It must feel like an original collectible monster, not a copy of any existing franchise creature.
Style/medium: high-quality retro handheld RPG pixel art sprite, crisp pixel clusters, limited 7-8 color palette plus eyes, clean 1-pixel dark outline, readable at 48x48.
Composition/framing: single full-body creature, centered, three-quarter front view, compact silhouette, generous padding.
Color palette: <palette>.
Scene/backdrop: perfectly flat solid #ff00ff chroma-key background for background removal.
Constraints: original design only; no text; no watermark; no UI; no floor; no cast shadow; no gradients; do not use #ff00ff in the creature.
```

## 폐기 기준

아래 중 하나라도 해당하면 다시 만든다.

- 몽글이와 비교했을 때 캐릭터성이 약하다.
- 몸통이 다른 종과 거의 같다.
- 대표 파츠가 48x48에서 안 보인다.
- 눈, 입, 장식이 흐려져서 얼굴이 뭉개진다.
- 포켓몬식 문법은 느껴지지만 고유 소재가 없다.
- 큰 이미지에서는 좋아 보이지만 48x48에서 의미를 잃는다.
